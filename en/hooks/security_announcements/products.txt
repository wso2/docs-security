# Official WSO2 product names. Pages name a product only as written here: each line of a
# security advisory's AFFECTED PRODUCTS and a CVE justification's REPORTED PRODUCTS must
# start with one of these names, and anywhere else in a page the content check
# (.github/scripts/check_content.py) rejects a listed old spelling and a difference in
# upper and lower case, such as "WSO2 identity server".
#
# To allow a new product, add its name on a line of its own, in the part where it belongs.
#
# To have `check_content.py --fix` correct an old or wrong spelling, add a line in the
# second part: "old spelling -> official name". Differences in upper and lower case only
# are corrected without a line here. An old spelling that does not start with "WSO2 ",
# such as "API Manager" or a product code such as "wso2am", is corrected only at the start
# of a product line and in the product column of an update-level table, since prose may
# use it as a short form.
