### AFFECTED PRODUCTS
* WSO2 API Control Plane: 4.7.0, 4.6.0, 4.5.0
* WSO2 API Manager: 4.7.0, 4.6.0, 4.5.0, 4.4.0, 4.3.0, 4.2.0, 4.1.0, 3.2.1, 3.2.0
* WSO2 Identity Server: 7.2.0, 7.1.0, 7.0.0, 6.1.0, 6.0.0, 5.11.0, 5.10.0


### OVERVIEW
Reflected Cross-Site Scripting (XSS) vulnerability in the authentication endpoint.


### DESCRIPTION
An error message generated by the authentication endpoint contains a reflected value from the request which could lead to an XSS.


### IMPACT
By leveraging an XSS attack an attacker can make the browser get redirected to a malicious website make changes in the UI of the web page retrieve information from the browser or harm otherwise. However since all the session related sensitive cookies are set with httpOnly flag and protected session hijacking or similar attacks would not be possible.


### SOLUTION

#### Community Users (Open Source)
Apply the relevant fixes to your product using the public fix(es) provided below.
* [https://github.com/wso2/identity-apps/pull/9718](https://github.com/wso2/identity-apps/pull/9718)
* [https://github.com/wso2-extensions/identity-outbound-auth-passwordPolicy/pull/80](https://github.com/wso2-extensions/identity-outbound-auth-passwordPolicy/pull/80)

If applying the fix or update is not feasible, migrate to the latest unaffected version of the respective WSO2 product(s).


#### Support Subscription Holders

Update your product to the specified update level or a higher update level to apply the fix.
