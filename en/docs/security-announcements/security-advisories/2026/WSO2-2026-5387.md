### AFFECTED PRODUCTS
* WSO2 Identity Server: 7.2.0


### OVERVIEW
Incomplete OAuth token revocation in specific environments where user store and database case-sensitivity are inconsistent.


### DESCRIPTION
In deployments that use a case-insensitive user store in combination with a case-sensitive database for identity data, mismatches in username case handling can occur. In such configurations, OAuth token revocation operations may fail to correctly identify usernames containing mixed-case characters, resulting in tokens not being revoked during certain lifecycle events.


### IMPACT
For this vulnerability to be exploited, a malicious actor must first possess a valid access or refresh token. Under affected configurations, these tokens, if associated with certain usernames, may not be revoked during lifecycle events that are expected to invalidate them. A malicious actor can use these access and refresh tokens, before they expire, to continue performing actions that should have been restricted.
