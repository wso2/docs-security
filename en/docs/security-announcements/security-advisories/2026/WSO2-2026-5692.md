### AFFECTED PRODUCTS
* Enterprise Integrator (BPS profile) 6.6.0 and below
* Business Process Server 3.6.0 and below


### OVERVIEW
Authenticated Remote Code Execution vulnerability via BPMN System REST APIs.


### DESCRIPTION
An authenticated user could provide a specifically crafted input to a BPMN System REST API endpoint which may lead to the execution of arbitrary commands on the server.


### IMPACT
An authenticated user may execute arbitrary commands in the context of the product's runtime account. The extent of the impact depends on the privileges of that account.


### SOLUTION

#### Community Users (Open Source)
WSO2 Enterprise Integrator (BPS and MB profiles) 6.6.0 has reached end of life as published in the WSO2 Support Matrix and no longer receives security updates. Customers requiring assistance with migration planning should contact WSO2 Support.
